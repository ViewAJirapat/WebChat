# ChatBook: progress log

A Facebook-like chat web app built by a **local LLM** (qwen2.5-coder 14B via Aider, architect mode)
through the swarm harness in `E:\Playground_Projects\04_AgentSwarm`. A chief (Claude) plans, writes
the specs and hidden tests through staff agents, issues `swarm` commands and reviews results; it
does not write the product's feature code.

**Ground rules**
- The harness repo `04_AgentSwarm` is not modified (owner's rule). It is driven with
  `uv run --project E:\Playground_Projects\04_AgentSwarm swarm -c E:\Playground_Projects\05_ChatBook\harness\swarm.toml ...`.
- Product repo: `05_ChatBook\chatbook` (git). Harness config, tasks, runs, worktrees: `05_ChatBook\harness`.
- The frame (core, protected) and each task's hidden tests and reference `solution.patch` are
  written by staff agents. Feature code comes only from the local LLM through the harness.
- Dev engine: `local-14b-arch` (the `claude` CLI is signed out, so no Claude engine).
- Update this file at every checkpoint (usage limits interrupt long runs).
